Welcome to **Flowbox**! This was a little project I created while I was bored and found it fun to play around with! If you enjoy using it, please share the project with friends as it does help it grow <3

### How to Use
There are two methods on how to use it! You can either use the official github page site (https://github.com/SoulDevOfficial/Flowbox) or you can download it from the releases section and play it locally! Just remember to check out the project's licence when doing so!
